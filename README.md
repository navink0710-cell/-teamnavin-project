# TEAM NAVIN
### Strength • Powerlifting • Performance

Team Navin is a strength and powerlifting performance project built around structured programming, athlete development, competition preparation, and long-term strength.

## Project goals
- Build a clear digital home for Team Navin
- Showcase powerlifting and coaching work
- Organize programming resources
- Track athlete development
- Provide a professional starting point for future tools

## Structure
- `index.html` — public landing page
- `assets/` — branding and media placeholders
- `docs/` — coaching and programming documentation
- `data/` — sample athlete/program data
- `scripts/` — optional future automation

## Run locally
Open `index.html` in a browser. No server or dependencies are required.
