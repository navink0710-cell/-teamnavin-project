# Team Navin Coaching System

## Athlete onboarding
1. Athlete profile
2. Training history
3. Current best lifts
4. Bodyweight and weight-class goal
5. Competition date
6. Availability and recovery constraints
7. Technical priorities

## Programming workflow
- Establish baseline
- Select training block
- Set progression model
- Monitor RPE / performance
- Review weekly data
- Adjust load or volume
- Deload when appropriate
- Transition toward competition specificity

## Weekly review
Track:
- Bodyweight
- Sleep
- Session RPE
- Main-lift performance
- Pain/injury flags
- Recovery
- Compliance
- Notes from athlete

> This document is a coaching framework, not individualized medical advice.
